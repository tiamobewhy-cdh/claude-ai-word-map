# AI 낱말 지도

ChatGPT와 Claude를 쓰며 마주치는 AI 용어 75개를 처음 배우는 사람 눈높이로 정리한 위키입니다. 2026년 10월 기준으로 작성했습니다.

## 들어 있는 것

- **14일 학습 플랜**: 하루 6~7개 용어 체크리스트, 복습·실습 미션, 진행률과 연속 학습 기록
- **전체 노선도**: 용어 75개를 7개 노선(기초, 프롬프트, 에이전트, 연결·확장, 자동화, 만들기, 안전·신뢰)에 배치
- **구조 한눈에**: 하네스, 메인 에이전트, 서브 에이전트, 도구가 맞물리는 방식과 8단계 예시
- **헷갈리는 짝**: 자주 섞어 쓰는 용어 8쌍 비교
- **용어 사전**: 검색, 노선·난이도 필터, 비유, ChatGPT와 Claude에서 보이는 이름
- **암기 카드**: 노선별, 일자별로 넘겨 보는 플래시카드
- **ChatGPT · Claude 대응표**

## 보는 법

GitHub Pages 주소로 열거나, `index.html`을 내려받아 브라우저로 열면 됩니다. 별도 설치는 필요 없습니다.

## 진행 기록 저장

체크박스와 "알아요" 표시는 보는 사람의 브라우저에 저장됩니다. 같은 기기의 같은 브라우저로 열면 이어지고, 다른 기기나 브라우저에서는 새로 시작됩니다. 함께 공부하는 사람끼리 기록이 섞이지 않습니다.

## 고쳐 쓰기

용어 데이터는 `index.html` 안의 `window.AIMAP` 부분에 모여 있습니다. 메뉴 이름이 바뀌면 해당 용어의 `gpt`, `cl` 값만 고치면 됩니다.
